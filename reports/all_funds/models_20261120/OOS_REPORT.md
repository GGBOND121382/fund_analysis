# P2 样本外验证报告：M0' / M1 / M2 / M3（asof 2026-11-20）

脚本：`scripts/run_oos_model_comparison.py`；数据：`oos_result.json` + 每折 TOP10（`fold_*.csv`）。

## 0. 设计与局限（如实声明，先于结论）

1. **M0 降级为三因子版（M0'）**：历史形成日无法统一定义"事前冲击事件窗"，SA 项移除，权重按 0.40/0.35/0.10 归一化为 0.4706/0.4118/0.1176。**本验证不声称覆盖当前 M0 的完整四因子版本**。
2. **幸存者偏差**：基金目录为 2026-11 当前存续目录，已清盘/转型基金不在池内。四模型同池，相对比较有效，绝对水平偏乐观。
3. **独立性**：7 个半年形成日（2023-05 ~ 2026-05），持有期 6 个月互不重叠，共 7 个独立观测。季度折未做（重叠持有期不作独立证据）。
4. **费用**：统一 0.1% roundtrip（无法 PIT 核验各时点费率，偏保守）。
5. **Bootstrap**：500 情景（P1 已验证 2000/5000 情景下排名稳定；500 情景含蒙特卡洛噪声，对 TOP10 组合层面影响有限）。
6. **交易资格未按历史时点过滤**（PIT 交易状态缺失），四模型同样处理。

## 3. 定量发现

1. **M0' 的收益分布极端化**：2025-11 折 M0' 赚 7.71%（全模型最佳），2026-05 折亏 36.72%（全模型最差）。M0' 的收益分位（权重 47%）会把当期高收益基金（含高波动权益/转债类）拉入 TOP10，形成"追涨"暴露；其在趋势延续期（2025-11→2026-05 上半段）获利，在反转期（2026-05 之后）承受 41% 回撤。
2. **M3 的尾部保护最明显但只在危机折兑现**：2026-05 折 M3 仅亏 3.28%（MDD 7.21%，同期 M0' −36.72%/41.24%）；但在 5 个平稳/上行折中 M3 跑输 M0' 达 4 次（胜率 2/7），其平均 ΔR=+3.72% 几乎完全由单一 2026-05 折贡献（该折 ΔR=+33.4%）。**M3 的优势依赖单一极端行情，不满足晋级标准第 3 条。**
3. **M2 相对均衡**：胜率 5/7，MDD 改善方向一致（ΔMDD 均值 −3.58%），且在 2023-11 折取得全模型最佳收益；但 2026-05 折仍亏 12.23%，尾部保护弱于 M3，且置信区间同样跨零。
4. **M1（EB 收缩）表现中性**：均值小幅改善（ΔR=+1.46%），回撤小幅改善，无显著特征；EB 的均值收缩在 2025-11 趋势折显著跑输（3.69% vs 7.71%），符合"收缩惩罚动量"的理论预期。
5. **回撤改善方向一致但不显著**：三个模型的 ΔMDD 均值均为负（M3 −5.73% > M2 −3.58% > M1 −3.06%），方向一致支持"高级模型的风险估计更保守"，但 n=7 的 t 区间均跨零。

## 4. 晋级结论

**OOS_UNDETERMINED —— 不升级任何模型替代 M0。**

逐条对照任务书晋级标准：

| 标准 | M1 | M2 | M3 |
|---|---|---|---|
| 1. 统计与经济意义的样本外改善 | ✗ CI 跨零 | ✗ CI 跨零 | ✗ CI 跨零 |
| 2. 未来最大回撤无实质恶化 | ○ 均值改善、不显著 | ○ 均值改善、不显著 | ○ 均值改善最大、不显著 |
| 3. 改善不依赖单一行情/极少数基金 | ✓（平平） | ○（5/7 胜率但幅度小） | **✗ 依赖 2026-05 单一折** |
| 4. 参数稳健性 | n/a | ✓（P1 敏感性通过） | n/a |
| 5. 数据质量与交易资格不差于 M0 | ✓ 同池 | ✓ 同池 | ✓ 同池 |

建议（非晋级，仅作后续研究方向）：

- **M3 的尾部保护价值真实但样本不足**：7 个独立折中只有 1 个危机折。若要验证，需要更长历史（2018/2020/2022 危机期）且必须解决历史基金目录的幸存者偏差。
- **M0 的 SR 高权重在极端行情中的尾部暴露值得组合层对冲**（见 P3 风险预算），而不是改评分公式。
- 当前主榜维持 M0 不变；M1/M2/M3 榜单保留在 `reports/all_funds/models_20261120/` 供研究对比。
