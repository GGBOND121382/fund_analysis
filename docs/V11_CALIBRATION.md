# v1.1 参数校准与有效回测：2026-11-11

## 为什么修改

旧B6只跑了2026-11-05到11-11、2个已披露净值观测日，不能用于收益/风险优化。
此前 `base_fraction=1.0`、`cash_reserve_weight=0.05` 均未经验证，且5%现金底线与研究候选接近0%的目标现金权重直接冲突。

该修订**不是**“找到了最优参数”，而是提供能在现有约507个共同交易日上执行、
使用完整历史的**预注册探索性参数选择实验**。

## 两种测试协议

默认半年窗口（有507个交易日时理论上可执行）：

- 训练252个共同交易日：仅用于生成战略目标权重；
- 训练→验证隔离3个交易日，避免T+2近似披露引入未来信息；
- 验证120个交易日：挑选B2/B6预注册策略；
- 验证→测试再隔离3个交易日，确保验证尾部净值在测试决策前已公开；
- 测试120个交易日：参数与权重冻结，独立计算费用、CAGR、MDD等。

主方案需 252+3+120+3+120 = 498 个共同交易日，而不是用满507日。

补充两个不重叠季度测试：252训练+3日隔离+63验证+3日隔离+63测试，folds=2，step=63。
两个测试折在日期上不重叠，但训练窗口滚动利用先前数据，统计独立性不可保证。

默认正式验收标准仍为训练、验证、测试各至少252个交易日；
以上两种 **EXPLORATORY** 模式都不能标记 `OOS_ACCEPTED`，
更不能据此宣称长期净年化>5%且未来回撤<=4%。

仅在本地拥有个人 `config/account_snapshot.json` 和 `data/nav/` 的机器：

```powershell

python scripts/run_v11_exploratory.py --asof 2026-11-11 --mode halfyear

# 额外诊断：两段不重叠季度测试
python scripts/run_v11_exploratory.py --asof 2026-11-11 --mode quarterly
```

运行结果：

- `reports/joint_strategy_optimization.json`：训练权重候选、验证期选参、冻结测试期和消融结果；
- `reports/V11_EXPLORATORY_REPORT.md`：B2与A1—A6测试对照；
- `reports/v11_exploratory_summary.json`：便于机器读取的结果摘要。

**注意** 两次运行会覆盖当前的joint JSON，脚本自动归档前一份，

## 什么参数值得比较

这不是高维随机调参，仅预先注册以下控制组和低复杂度候选：

| 规则 | 基础投入比例 | 择时释放旧现金 | 止盈 | 止损 | 用途 |
|---|---:|---:|---|---|---|
| B2 | 原B2水位法 | 无 | 否 | 否 | 原策略参照 |
| A1 | 100% | 0% | 否 | 否 | B6风险门基准 |
| A2_base75 | 75% | 0% | 否 | 否 | 延期25%资金 |
| A2_base50 | 50% | 0% | 否 | 否 | 延期50%资金 |
| A3_timing75_release50 | 75% | 50% | 否 | 否 | 加仓择时信号 |
| A3_timing75_release100 | 75% | 100% | 否 | 否 | 研究择时资金释放幅度 |
| A4_takeprofit | 100% | 0% | 是 | 否 | 止盈贡献 |
| A5_stop | 100% | 0% | 否 | 是 | 止损及重入贡献 |
| A6_joint75 | 75% | 50% | 是 | 是 | 完整策略 |
| A6_joint50 | 50% | 50% | 是 | 是 | 更保守的动态投入 |

全部B6候选 `cash_reserve_weight=0`，与当期B2目标现金近零的研究基线保持可比。
如要测试现金储备1%/2.5%/5%，需把 **B2和B6战略现金权重共同改变**，
单独研究现金缓冲，而不能只给B6加5%约束。

延期现金持有期10个交易日到期后，只要公开时点的风险门PASS、账户现金充足，
即使没有趋势信号也会安排释放；风险UNKNOWN/FAIL时阻断到期释放，并显式记账。
这是延期限期**目标**，不强制在风险不可控时购买基金。

**研究假设，不是最优参数**：暂取`deferred_horizon_days=10`、`risk_paths=64`、
`fee_stress_bps=30,60`、`max_fund_weight=0.40`。
若首次研究有清晰改善，再预注册新的期限5/20天与风险参数验证，
不要直接对短测试期无限调参。

## 样本外消融为何仍有限

- 仅有507个共同交易日，无法做多个独立完整年度验证；
- 原基金短历史、真实批次缺失、统一费率不是实际申赎费用；
- 宏观债券Carry和信用利差因子尚未接入B6；
- 训练期选权重，验证期选规则，**测试期的每组消融仅用于诊断**；
  不得在看到测试最佳规则后将其当作独立测试成功；
- 必须核对真实的BUY/REDEEM事件、现金占比、申赎锁定期及费后收益；
- 没有充分证据时返回`DATA_BLOCKED`、`RETURN_TARGET_UNMET`、
  `EXPLORATORY_NOT_LONG_TERM_VALIDATED`，绝不放宽5%/4%目标。
