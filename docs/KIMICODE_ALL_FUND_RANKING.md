# 全类型基金榜单 · KimiCode 交接

目标是交付一份**完整的全市场目录审计和全部可评分基金的同类榜单**，不是每组前十，也不是再跑几个示例。纳入东财公募基金目录中的全部类型，包括股票、指数、各类混合、债券、FOF、QDII、商品、货币、公募 REITs 和类型未分类记录。持有期、申赎和限额不作筛选条件。没有把握的数据保留在全量审计里，不补造净值、不用过时数据给名次。当前目录是现有公募目录快照，不是包括已清盘基金的无幸存者偏差历史数据库。

## 直接跑全量

PowerShell 和 bash 都可以执行：

```text
python -m pip install -r requirements.txt
python scripts/run_all_fund_ranking.py --asof 2026-11-12 --workers 6
```

默认使用 `data/all_funds`，不会覆盖已有策略或账户缓存。可随时中断，再跑同一条命令续传。每只基金的缓存单独写盘，已达到截止日的不重新请求。失败和过期的会再试。不要用 `--refresh-catalog` 改变同一次实验的目录口径。文件保留目录日期范围内已公布数据，不使用截止日之后的价格。

若基金 QDII、FOF 等公告有延迟，不得把实际获取日当净值日期，也不要用前值填充。正式结果可等公告补齐或固定一个共同更早交易日重跑，并在报告写清楚。不同类型因估值规则、假日、公告滞后而产生的缺口须单独统计。对源站偶发失败，合理分批重试，不要提高到激进并发。对于确认已终止、缺历史、跨市场日期休市等情形，记录原因后归入未评级，不能只删除。已有可靠、复权口径可验证的本地数据时，可将目录和相应缓存放入同一 `--data-dir` 后加 `--skip-fetch` 只重排。

## 定义

- 收益、回撤、抗冲击分别评分。同组同历史档做百分位并等权，先 Pareto 前沿，再综合分、最弱分和代码。输出完整同类排名，不把货币和股票混成单一榜首。分组按供应商细类，美元、港元、欧元份额分开。未标币种按人民币归类，供尽调复核。
- 6 个月是观察档，1/2/3 年为独立分档。短历史不冒充一年数据。流动性字段没有来源就保持未知。
- 普通基金用单位净值结合分红或折算日的供应商复权回报，拒绝明显无法核对的公司行为。若复用旧原始净值缓存，配合独立的分红及折算数据。基金净值并非 ETF 场内成交价。货币基金用实际万份收益重建复利，不用 7 日年化，也不用缺报时的零收益。普通货币遇到未标注的断点时，只用最近的连续日历区间。浮动净值货币使用净值。场内货币若无可核实的万份收益则列为未评级，不用可能恒定的场内价格冒充总回报。国内公募 REITs 采用供应商后复权场内收盘价，独立分组，含场内折溢价风险，指标不等同于基金净值回撤。
- 共同事件有 A 股普跌、6 月长债调整、10 月末信用与长债冲击、11 月再调整。商品与海外组各另加一个公开事件。相同组和历史档用同样的窗口，数据不足不强行评分。冲击分是历史截面，不等同于样本外风险或组合 4% 回撤承诺。
- 完整榜单含已评分的产品代表份额。原始全量中所有 A/C 等份额逐条保留，可用 `universe.csv` 找任意代码。未知分类仍纳入审计。需要穿透持仓、久期或权益暴露时另做，不由基金简称推断实际风险。

## 交付和验收

`reports/all_funds/`：

- `ranking.csv` 全部可评分代表份额，每组按名次排序，不截断。
- `universe.csv` 目录全部份额、指标、分类、数据和入榜状态。
- `unranked.csv` 无可比分数或同基金其他份额，包含理由。
- `shortlist.csv` 仅辅助阅读的每组前列，不能作为完整榜单。
- `watchlist.csv`、`summary.md`、`audit.json`、`type_coverage.csv`（原始细类覆盖）。
- `data/all_funds/fetch_audit.csv` 是逐代码抓取日志。全量运行入口会复制为结果目录的 `fetch_audit.csv`，不要提交原始全量净值缓存。

逐类核对目录份额数、有效精确日期净值数、可评分产品数、缺失原因。检查目录、`universe.csv` 行数守恒，以及 `ranking.csv + unranked.csv` 行数等于全目录。确认 025368 和 019851 都在全量审计，逐项复核数据与分档。对仍缺失的类型说明缺口，不把缓存试跑写成全量排名。全量采集后交付 CSV 和摘要即可，代码无需先并入主分支。
