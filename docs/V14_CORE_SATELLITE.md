# v1.4 核心—卫星研究基线

本版只做核心—卫星仓位约束、固定金额定投、超限再平衡、逐基金回撤归因。PE、择时、主动抄底都不在本版。原有 v1.3 CLI、账户与交易配置保持不变。该命令不读真实账户快照，不下单。

## 在现有本地仓库运行

保留已有 `data/` 目录。下列示例用 2026-11-12 抗跌短名单回放更早窗口，**明确是回看诊断，不是独立样本外验证**。

```powershell
python -m pip install -r requirements.txt
python scripts/run_v14_research.py --start 2026-05-12 --end 2026-11-09 --diagnostic
```

若报缺数据，只抓相关基金。已有状态、净值和分红缓存可直接使用，不必重新拉全市场净值。

```powershell
python main.py list
python main.py fetch --codes "022379,006488,472007,021695,003315,110020,000218"
python main.py dividends
```

测试增强债和受约束 SOCP 时另准备两只基金历史：

```powershell
python main.py fetch --codes "021559,018604"
python scripts/run_v14_research.py --start 2026-05-12 --end 2026-11-09 --diagnostic --optimizer --enhancement-target 0.05 --output reports/v14_with_optimizer
```

- 默认每日入金 1000 元、初始空仓、无真实存量迁移。可用 `--daily-inflow` 修改。由于申购限额按金额执行，改变名义本金和入金会改变结果。`--initial-cash` 是未投资现金，不会绕过每日入金额度直接建仓。
- 若提供自定义 `--universe`，格式见默认 JSON。短名单日期必须早于回测起点，否则要显式加 `--diagnostic`。系统不会把后验名单冒充成早期可选池。当前只支持冻结的、用户给定日期的名单，不自动重建历史基金池。
- 为避免比较日期漂移，所有策略共用本次基金净值日期的并集及共同最新截止；基金当天缺净值不成交。每只基金要有回测前净值，任何缺文件直接提示代码，不静默剔除。净值披露沿用推定 T+2 自然日 23:59，申赎状态只用当前快照替代历史，实际费率与不同基金到账规则未补齐。费率默认单边 60 bp 压力代理，`--fee-bps 30` 可另跑敏感性。
- 无交易状态或分红文件默认报错。显式使用 `--allow-missing-trade-status` 或 `--allow-missing-dividends` 得到有对应缺失标记的研究结果，不可视为完整证据。

## 本版比较与计算

1. 0%、5%、10%、15% 为**卫星硬触发预算档位**。卫星目标通常是上限的 80%，单只基金上限 25%，单组卫星子上限为 7.5%，每类核心债上限为 55%，增强债合计上限为 10%。这些是实验约束，不是经过校准的最优仓位。纯核心和固定定投基准都不自动加入增强债。
2. 入金补目标缺口，按下单前可见净值估算。单基金/分组/卫星总约束都同时检查，按可申购状态及限额裁剪，且不超实际现金。超限时只发赎回意向，目的地是目标与触发线的中点。不能赎回的份额不算可用现金，赎回日与申购日分开，实盘净值未知造成的成交后被动超限单独计数。
3. 风险门采用三个预先定义的同步压力，不从这段回测反向校准。若已经回撤 d、额外情景损失为 l，则组合压力回撤为 d + (1-d)l。用已披露的组合单位净值计算 d。风险门暂停增加风险，不声称它能控制实际 MDD。固定定投对照使用同一目标、不设日常上限再平衡或压力门，仍保留申购状态与限额。
4. SOCP 为可选对照，严格使用回测开始前已披露的至少 252 个共同收益。它复用 v1.3 一年收缩均值与联合块抽样，增加分组线性上限和独立压力路径回撤约束，求解后复核恒定权重风险。不足则单独报告阻断。它不是动态交易最优解，也没有校准债券指数收益先验。
5. 日贡献拆为原持仓净值变化、分红、现金利息与逐基金交易费，再按单位净值链接。外部入金不算收益。区间贡献总和等于区间 TWR。最大回撤峰谷段的正向损失贡献之和等于 MDD，负值表示抵消损失。历史真实账户的损益或回撤不在本研究范围内。

输出 `summary.json`、各策略 `*_daily_attribution.csv`、`*_weights.csv`、`*_execution_audit.csv`。摘要包含 5%／4% 历史窗口判定、压力结果、实际被动超限天数、费用口径和证据限制，不会导出本金或申赎金额。即使某个窗口达标，也不表示长期目标或未来回撤有保证。
