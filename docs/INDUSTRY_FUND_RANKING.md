# 四期限同类基金发现榜与前推检验

这是研究筛选，不是买入清单，不修改交易或组合策略。现有全市场榜及输出保留。

## Kimicode 一键全量

在有既有全市场日净值缓存的仓库根目录运行。旧采集器通常只保留三年加一个月。新入口默认尝试补到九年，同步当前截面并覆盖最早一次五年回看。已完成的抓取可重用，中断后重复执行同一条命令即可。

```powershell
python scripts/run_industry_fund_ranking.py --asof 2026-11-12 --data-dir data/all_funds --output reports/industry_rank --fetch
```

如果缓存已经包含足够历史，可去掉 `--fetch` 离线计算。不要用原来只有汇总指标的 CSV 或 Excel 当作日净值输入。日净值读取 `data/all_funds/total_return`、`money`、`listed`，也可用原 `nav` 与分红/拆分表作为净值后备。联网抓取使用公开东方财富基金净值及腾讯 REITs 后复权收盘价。批量抓取耗时取决于网络、剩余缺口与品种类型。若源头没有足够历史，保留可核验的短序列与原因，不外推、不填零。快照日选所有可比品种共有的交易日，缺该日净值的样本单列。

正式前推如有逐期历史目录，把各形成日的 `YYYY-MM-DD.csv`（列为 `code,name,type`）放同一目录，增加 `--pit-catalog-dir <目录>`。必须每个形成日都有精确文件。退市/清盘产品的日净值也须放在缓存中，当前公募目录的联网抓取不保证覆盖已退出产品。未提供历史目录时，脚本明确标记为在当前目录上回放，不能消除幸存者偏差或类别变更。缺未来净值不当作零收益，不在形成期预先排除。尚不模拟实际认购开放状态、申赎费、锁定期或清盘兑付。

## 排名方法

- 5 年、3 年、1 年、半年独立入榜。同一分类、基金、币种、计价方式只保留一份额，优先 A 份额。长封闭定开债单列，持有期与低流动性不扣分。原异常规则只在低波分类和各自评价期限内检查单日涨跌超过 3% 的样本。缺历史或待核验的标的分别进 `unranked_*.csv`。
- 收益项取区间复权收益，三年及五年转年化。稳定性取同类等权平均之上的完整日历月占比，采用当期比较样本的月收益，月中截点的半年榜用五个完整月。下行损失取负月收益之和的绝对值，频率与亏损月平均跌幅也独立输出。回撤取日净值峰谷。分位为平均并列名次转成 0–1，较优为高分，绝对指标一并保留。
- `research` 为收益/稳定性/下行损失 = 50/25/25，未宣称最优。`industry_proxy` 为济安金信 2019 年公开因子与权重的同类分位实现，短债/中长纯债/利率债/信用债/一级债基用 67/33，二级债基用 56/22/11/11（最后两项为亏损频率、亏损月平均跌幅）。其他组不套用债基公式。不是复刻机构星级，也不把短期诊断称作正式评级。
- `legacy` 为收益/区间最大回撤/两轮最差冲击回撤/两轮最差冲击收益 = 35/35/20/10。当前榜按此前 10 月末、11 月两轮窗口复算。不同历史长度、异常核验与产品分组可能改变可比样本。完整样本表中旧分数只使用有两轮数据的基金。`matched_*.csv` 把所有方案重算在同一基金池，适合比较名次变动。
- `return_only`、`drawdown_only` 和 `preservation` 是简单基线，分别只看收益、只看区间最大回撤、只看负月损失（参照理柏 Preservation 思路，并非官方评级）。Pareto 标签在四项旧指标都有数据时计算，四项分别为收益、最大回撤、冲击回撤、冲击收益，不是所有风险维度的全面占优。
- 压力表不计入新主分，按独立窗口列累计收益、最大回撤和回到该次回撤前峰值所需日历天数（从谷底起算）。未修复、缺窗口和无回撤分开。事件需有起止和窗口工作日记录，缺历史的新基金不因 2022 年事件缺失被淘汰。

## 前推验收

默认 12 个不重叠的三个月观察窗。形成期只看形成日及之前已观察到的数据，评价使用之后第一个有净值的日期作为入场代理。旧法的历史对照只取评价期限内已经结束的最近两轮适用债市事件，不足两轮则不生成旧法名次。

同一形成日、同期限、同组、同一候选池，所有方法各选前 20%（上限 `--top`）。`all` 组比较不需要压力事件的方案，`stress_matched` 组比较包含旧法的共同样本。只在同一折所有对照方法入围产品都可观测时计算配对差异。输出各方法所选基金的后续收益与回撤的中位数，不是等权组合回测。当前目录回放即使完整，也只能作为诊断，不可据此声称已在无偏历史池或未来验证。

验收先看覆盖，再看配对差异。报告 `research` 相对收益榜、回撤榜、行业代理和旧榜的未来收益与回撤差，而不是只报一个综合平均。先列同类共识候选，再检查压力事件及风险暴露。若收益改善但回撤也上升，按明确取舍报告，不能称为两项同时改善。组合长期年化 ≥5%、最大回撤 ≤4% 是后续组合验证目标，不是单只基金门槛。

| 输出 | 用途 |
|---|---|
| `ranking_{5y,3y,1y,6m}.csv` | 四期限完整同类研究榜，含原始指标与多套名次 |
| `matched_*.csv` / `shortlist_*.csv` / `unranked_*.csv` | 同池对照 / 发现候选 / 不排名原因 |
| `consensus_*.csv` | 共同样本内，新旧法均进同组前 N，适用时行业代理也须进前 N |
| `stress_events.csv` / `watchlist.csv` | 单事件压力与修复 / 025368、019851 的期限归属 |
| `oos_selections.csv` / `oos_folds.csv` | 每只入围基金、形成和评价日、配对覆盖 |
| `oos_paired_deltas.csv` / `oos_summary.csv` | 同折差值和分组汇总 |
| `audit.json` / `coverage_by_group.csv` / `nav_audit.csv` | 覆盖、取样、缺失及验证口径 |
