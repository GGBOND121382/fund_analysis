## 1. M0主榜公式：固定40%/35%/15%/10%

对i基金、h窗口，复权后净值V(t)、窗口起始t0、截止T，Y=(T-t0)/365.2425。

(1) 年化历史收益（越高越好）：
    R(i,h) = exp(log(V(T)/V(t0)) / Y) - 1.

(2) 完整观察窗口最大回撤（越低越好）：
    D(i,h) = max_{t0<=t<=T} { 1 - V(t) / max_{t0<=s<=t} V(s) }.

(3) 月度下行风险（越低越好）：仅使用窗口内**完整月度**的月末至下月末回报r(i,m)，共k个：
    L(i,h) = sqrt((1/k)*SUM_m [min(r(i,m),0)]^2).
2026-11-20的6m窗口通常有6—10月这5个完整月度收益；5月末是计算6月完整收益的**端点**，不能把5月下旬计为一整月，也不能把未完成的11月计为一整月。k不足或完整月收益缺失时标记，不得当作零下行风险。

(4) 近期债市调整观察：统一已知区间 2026-10-29 至 2026-11-13（非预测），要求净值端点及区间有效观测。
    Aret(i) = V(2026-11-13)/V(2026-10-29)-1.
    Add(i)  = max_{t in event} (1-V(t)/max_{s<=t,s in event}V(s)).
将两项分别评分。该共同事件刻画这一段历史的债市调整敏感性，不自动代表所有资产类别的长期风险。

(5) 分位标准化：对同一期限全部四项完整、估值可比的候选U_h，N=|U_h|，rank_asc为升序**平均并列名次**：
    Pplus(x_i)  = 100*(rank_asc(x_i)-1)/(N-1).
    Pminus(x_i) = 100-Pplus(x_i).
若N=1统一给50；缺失不可给0、50或100，要显式UNSCORED。四项独立在**相同候选集合**上算百分位。

(6) 四项分数与总分：
    SR = Pplus(R);
    SD = Pminus(D);
    SL = Pminus(L);
    SA = 0.5*Pplus(Aret)+0.5*Pminus(Add);
    SCORE_M0 = 0.40*SR + 0.35*SD + 0.15*SA + 0.10*SL.
按照SCORE_M0降序、code升序确定原始名次；不附加Pareto优先级，不使用隐含的经验贝叶斯、Bootstrap、4%预算、额外主观惩罚或阈值加权。总分为0—100。

检验反例：A四项评分(100,0,0,0)得40分；B(60,60,60,60)得60分。即使A是Pareto非支配对象，也不能自动排在B之前。一个高收益高回撤基金**仍可能根据透明总分胜出**；遇到这种情况必须披露各分项得分和历史MDD，不得看榜改权重以迎合预期。

## 2. 资格、异常、去重：分别输出，严禁静默删除

- **全集状态**：每个目录code在每个h都有一条全量记录；status明确区别有效得分、缺历史、净值错误、特殊估值/异常平滑待核验、事件期缺数据、重复份额、交易未知和已确证不可交易。计算覆盖数总和必须等于输入唯一code数。
- **风险异常**：正收益且净值最大回撤<=0.0002（即0.02%）只触发平滑/估值复核，不是自动证明摊余成本或真实风险为零。疑似摊余成本法、复权错误、低波基金单日>3%等均标记。未具备可比经济风险的异常产品不进入风险可比默认研究TOP10，但保留原始指标、待核验原因、代码与名字；不能伪造风险分。
- **交易四态**：VERIFIED_TRADEABLE、CONFIRMED_BLOCKED、UNKNOWN、PLATFORM_SPECIFIC。已知锁定期、封闭、确证停止申购或金额限制不满足者不进入可交易榜；UNKNOWN放到研究候选且明确标注，不允许从全集消失，也不可宣称可交易。某单一平台暂停申购仅说明该渠道，不能直接当作全平台禁止交易。以合同/公告/实际来源及known_at为准，名称正则只触发复核。
- **时间纪律**：2026-11-23抓到的交易状态不能冒充2026-11-20形成日已经知道；可以作为当下交易参考，但不能用于历史时间点的已核实资格。
- **份额与指数去重**：计算各份额分数后，展示榜内同一基金产品键只取一个有实际依据的代表；若有底层指数ID，指数相同的ETF/联接基金去重。只有“银行”等关键词只能说明主题相近，不能假称同一指数；另输出主题分散榜。原始全市场排名表仍保留所有基金及份额。
- 全市场比较之外额外输出**同类基金内排名**，作为解释性补充；不能让同类百分位悄悄替代全市场分数。跨币种/特殊净值基准不可比需独立标记。
