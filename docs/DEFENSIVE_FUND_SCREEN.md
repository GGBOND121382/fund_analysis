# 稳健基金分组筛选

新版筛选入口为 `scripts/screen_defensive_funds.py`。原 V13 抗跌总榜、59 只短名单及其冻结回测不变。新版是研究筛选，不自动改变组合配置或交易规则。

## 覆盖范围和数据口径

- 国内债券型基金、偏债混合基金均纳入。中短债、中长纯债、利率债、信用债、一级债基、二级债基、可转债、偏债混合分组比较。
- 持有期、定开、暂停申购、赎回状态、日限额仅记录，不作研究筛选门槛。未知交易状态留空，不视为可买。配置和执行时仍按实际持有期和申赎规则处理。
- 每个产品保留一个代表份额用于同组评分，优先长历史，同档优先 A 类。全量审计保留其他份额。分类和份额归并基于基金清单，不等于季报穿透验证。
- 净值需要精确匹配截止日。股息及折算在回报重建时调整，累计净值可用于核验。没有截止日净值、冲击期间缺数据、不明分红或份额折算都留痕，不能作为抗跌证据。净值单日绝对变动超 3% 标为待复核，不直接判定错误。
- 日历窗口分别计算 6 个月、1 年、2 年、3 年的收益和回撤。没有完整一年时进入 6 个月观察档，绝不把不足一年收益当成近一年收益。每档独立比较，跨档分数不可直接横比。长期档另外报告年化收益，6 个月不年化。
- 冲击窗口由 `config/defensive_fund_shocks.json` 定义，包含 A 股普跌、6 月长债调整、10 月末信用与利率债冲击、11 月再调整。每段记录累计收益、最大回撤，各产品用相同日期比较。须有首尾和全部窗口内工作日净值。自定义窗口若含休市日，请将其拆开或另选窗口。至少两个完整事件才运行，纳入评分须覆盖本次定义的全部事件。

## 如何综合评价

三个维度等权是可解释的初始口径，不是最优参数。每个维度先转为同类型、同历史档内的百分位：

1. **收益**。6 个月观察档看 6 个月，1 年档看 1 年，2 年档看 1 年和 2 年，3 年档看 1 年、2 年和 3 年，同维度平均。
2. **回撤**。同一组期限取最大回撤，方向取越低越好。
3. **抗冲击**。比较各窗口中最差的累计收益、最大的回撤和回撤中位数。最差累计收益与最大回撤不一定来自同一事件。

先列出在这三个分数上未被全面超过的候选（Pareto 前沿），再按三维等权分数、最弱维度分数、基金代码排序。每个组和历史档默认最多取 10 只，前沿不足时由后续排名补足。少于 3 个同组同档可比产品时只展示指标，不给名次。

这是一份历史截面筛选，四次冲击不等于完整压力测试。不能用它反推过去的投资决策，也不能把样本回撤等同于未来最大回撤或组合 4% 回撤约束。

## 运行

已有全市场净值和复权缓存时可直接运行第三条。要补齐偏债混合，先更新基金清单并按类别补净值，分红缓存缺失时再更新。市场范围大，耗时取决于已有缓存及数据源限流。

```powershell
python main.py list
python main.py fetch --types "债券型,混合型-偏债" --sources "em_f10,danjuan,em_js" --workers 6
python scripts/screen_defensive_funds.py --asof 2026-11-12
```

默认写入 `reports/defensive_funds/`：

- `universe.csv` 保存所有范围内份额的指标、三维分数、样本和剔除理由。
- `shortlist.csv` 保存分类分档入围名单。
- `watchlist.csv` 及 `summary.md` 显示 025368、019851 和原观察标的。
- `audit.json` 记录覆盖数量、各组样本状态和每个冲击窗口。若本地只有部分净值，不得把输出名次当作全市场排名。

可用 `--data-dir` 传独立的基金清单及缓存目录，避免覆盖实盘数据。使用 `--watch` 可以指定其他代码，`--output` 可将不同试验写入独立目录。
