# v0.8 算法修改说明：目标权重求解与 5%/4% 风险目标

> 状态：**RESEARCH_ONLY**。本版已改动源代码，非一纸设计方案。但未取得真实净值/账户流水，因此未验证任何基金的实际最优配置、收益或回撤。

## 0. 正式目标及无法保证的条件

- 目标年化**净**收益：`CAGR > 0.05`。
- 整体组合未来最大回撤风险预算：`MDD <= 0.04`，仅可作为**历史和场景筛选约束**，不能承诺未来的硬上限。
- 目标是完整账户（包括已经持有的沪深300和QDII存量），不是只优化债基后把其余资产当成现金。
- 风险优先：没有满足4%回撤预算的候选时返回 `RISK_CONSTRAINT_UNMET`；满足风险但收益证据不足时返回 `RETURN_TARGET_UNMET`；不会人为调高收益预测。

## 1. 决策变量

设可投资集合为 `i=1,...,n`：目标权重 `w_i >=0`，现金目标 `w_c>=0`，且 `sum(w)+w_c=1`。

- 当前持有但禁止新增申购、缺乏真实赎回批次的股票指数基金：`w_i=w_i^{snapshot}`，不得假设已卖出。
- 其他基金：`0<=w_i<=u_i`（默认每只60%，**未经实证校准**）。
- 现金目标 `w_c>=c_min`，默认0；应通过真实申赎需求来选择，不能盲目采用默认值。
- 原B2水位法在得到 `w*` 后解每日申购金额 `a_i,t`，真实赎回依旧遵守原模拟器的批次限制；本版没有直接自动买卖。

## 2. 回报与路径风险

先使用截止 `asof` 已经公开的**分红调整后日收益率**，严格对齐所有账户持仓的共同交易日。不允许对缺失基金填0%。若使用当前风格窗口，`--regime-start` 必须有真实季报证据。

模拟一日固定权重再平衡的组合收益：

\[
 r_{p,t}(w)=\sum_{i=1}^{n}w_i r_{i,t}+w_c r_{c,t}.
\]

路径复利净值：

\[
 P^{(s)}_t(w)=\prod_{\tau=1}^{t}[1+r^{(s)}_{p,\tau}(w)].
\]

单路径最大回撤：

\[
 D^{(s)}(w)=\max_{1\le t\le H}\left(1-\frac{P^{(s)}_t(w)}{\max(1,P^{(s)}_1(w),\dots,P^{(s)}_t(w))}\right).
\]

候选权重需满足：

\[
 \max\{\mathrm{MDD}_{\mathrm{hist}}(w),\;Q_{.95}(D^{(s)}(w))\}\le 0.04.
\]

使用完整历史连续窗口 + 同日期联合移动块Bootstrap（默认块长20与60日）；**所有基金同时以相同日期块抽取**，不破坏基金间相关性。默认192路径/块长、2400权重候选。这些只是预设搜索预算，不能被视作统计保证。

收益证据采用模拟一年净收益的25%分位：

\[
 G(w)=Q_{.25}\left([P_H^{(s)}(w)(1-c\,T(w))]^{252/H}-1\right),
\]

其中 `c` 是研究假设的换仓成本率，`T(w)=0.5||w-w_current||_1`。**这个25%分位不是“95%置信下界”，也不能证明未来收益 >5%。** 没有真实费率时默认成本0并标记未验证，不得据此进入实盘。

## 3. 求解算法（源码真实实现）

`fundkit/weight_optimizer.py`：

1. 生成100%（扣除冻结仓位）现金、单只基金持仓上界、当前权重、等比例候选，以及多种Dirichlet浓度下的随机可行候选。
2. 对每个候选按**真实复利路径**评价历史MDD、场景MDD 95%分位与模拟收益25%分位。
3. **先剔除**超出4%回撤风险预算的候选；再从剩余候选中最大化收益25%分位，优先低换仓量。
4. 使用**不同随机种子**的独立重采样对选中候选复核。不通过时输出 `INDEPENDENT_SCENARIO_REJECTED`。
5. 没有满足风险约束的候选时仅返回风险最小诊断，不能执行。

这是**有限候选、风险优先、可复现的情景搜索**，不是全局最优证明，也不是直接求解多期非凸MDD约束。独立种子仅检查模拟稳定性，不等于真正的日期样本外。

## 4. 与v0.7原代码的连接点

- 新CLI：`python main.py optimize-weights --asof 2026-11-10 --regime-start 2025-06-01`
  - 不主动联网；使用现有 `LocalDataAdapter`/AKShare本地净值缓存。
  - 输出 `reports/weight_optimization_research.json`；即使 `SCENARIO_CRITERIA_MET_UNVALIDATED` 仍不可直接交易。
  - 默认包含所有13只持有基金；遗漏非零持仓即 `DATA_BLOCKED`。
  - 2026年快照不可倒灌用于2025年策略训练；历史模拟应通过 Python API 注入当期反事实/真实持仓状态。
- 可将训练期间生成的报告**冻结**传给后续区间B2—B5：
  `python main.py sim --policy B2 --start YYYY-MM-DD --weights-report reports/weight_optimization_research.json`
  - 报告 `data_end` 必须严格早于回测开始日，禁止未来数据泄漏。
  - 只修改历史模拟时的B2目标权重，不覆写`config/policy_params.json`和`decision`真实交易建议。
- v0.7的B0—B5样本外程序已将指标更正为 `CAGR>5%、MDD<=4%`，但它**仍然只测试固定候选目标权重**；新求解器还没有形成完整的“滚动训练权重 → 独立日期验证 → 真实逐笔模拟 → 止盈止损超参联合搜索”实验链。
- 原`decide`在未经验证时将“目标权重”设为`null`，不再把45%/35%等未经验证的参数展示为最优组合。

## 5. 数据依赖分级

**数学上不依赖真实数据的部分（本次已实现/验证）：** 情景搜索、权重守恒、冻结仓位、收益与回撤路径、约束检测、独立种子重检、缺失和时序阻断、时间冻结模拟权重交接。

**需要真实数据才能得出投资结论的部分：** 各基金真实复权净值及分红、月度/季度持仓及公告公布日期、银行资本债信用利差/债券久期、当前逐笔基金份额/实际申赎费率及到期日、历史账户入金/赎回流水。行情数据应由既有AKShare工程提供；本版不重做采集。

## 7. 文献依据与边界

1. Chekhlov, Uryasev & Zabarankin (2005), *Drawdown Measure in Portfolio Optimization*, International Journal of Theoretical and Applied Finance. 路径回撤/CDaR的理论依据；并不证明这里使用的4%或场景95%是最优阈值。
2. Boyd et al. (2017), *Multi-Period Trading via Convex Optimization*, Foundations and Trends in Optimization. 资产目标、交易成本、流动性和滚动优化框架。**本代码尚未实现论文中的完整凸多期优化器。**
3. Vanguard (2024), *The Rebalancing Edge: Optimizing Target-Date Fund Rebalancing Through Threshold-Based Strategies*. 使用现金流和仓位偏离进行再平衡有行业研究支持；不能将其200/175bp直接挪用到你的纯债配置。
4. Kaminski & Lo (2014), *When Do Stop-Loss Rules Stop Losses?*, Journal of Financial Markets. 条件止损可能有效，但不是对所有基金和所有阈值都有效。
5. Künsch (1989), *The Jackknife and the Bootstrap for General Stationary Observations*, Annals of Statistics. 块Bootstrap保留局部时间依赖的统计依据，但不代表历史重采样覆盖未来结构性信用事件。

**结论：** v0.8完成了“从固定45%/35%到真正的数据驱动目标权重情景搜索”的算法层实现；没有拿到数据前，可以严格测试计算逻辑，但不能声称已经求出可靠的基金定投比例或5%/4%可行策略。
