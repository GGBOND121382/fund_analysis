# v1.5 零申购费重跑

申购费为 0 bp。赎回费独立设为 60 bp 压力代理，不代表实际渠道费率。没有套用真实逐基金、逐持有期的赎回费表。基金净值已反映的日常费用不另外扣减。本次保留同一净值、分红缓存、候选名单和日入金口径，费率同时用于回测成交和下单预估。SOCP 的换仓费用按相对于固定研究参考权重的买卖方向计算，不使用账户持仓。

## 验收与复跑

- 半年窗 SOCP 全核心为 +2.45%／0.12%，固定全核心为 +2.58%／0.14%。其余两窗在测试起点前的共同训练样本不足，SOCP 标记为 `DATA_BLOCKED`。
- 较早窗口的四个 15% 卫星上限案例短窗达到年化 ≥5% 且回撤 ≤4%。最近半年和全年无案例同时达到两项阈值。候选名单晚于测试期，且最近两个窗重叠，不能验证长期目标。
- 旧 A5 在最近两个窗空仓启动时无成交，不参与有效策略比较。当前申赎状态用于回放，不是历史逐日渠道记录。
- 145 项自动化测试通过，包含方向费用、费用归因和 SOCP 换仓成本验证。

```powershell
python scripts/run_v15_research.py --start 2026-05-12 --end 2026-11-09 --diagnostic --valuation-csv data/factors/csi300_valuation_proxy.csv --optimizer --enhancement-target 0.05 --legacy --output reports/v15_zero_subscription_halfyear
```

将日期改为 2025-11-10 至 2026-11-09 可复跑全年窗，改为 2025-01-02 至 2025-11-07 可复跑较早窗（本报告较早窗不带 `--legacy`）。分别指定输出目录。增加 `--redeem-fee-bps 0` 可复跑零赎回费对照。
