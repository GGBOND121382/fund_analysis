# 基金发现 v4：直接用已有净值生成收益—风险综合榜

## 核心结论

不需要补全外部基金合同、未来收益预测、类别基准或历史基金目录，就可以利用已有完整净值缓存计算四个历史观察窗口（5y、3y、1y、6m）的**风险调整研究排名**。上一轮 v3 只按历史收益输出 top10_historical_return_DIAGNOSTIC_*，并不是用户要求的榜单；它现在只保留作对照。

新的正式研究展示文件是 top10_risk_adjusted_{5y,3y,1y,6m}.csv，以及不做同一主题指数去重的 top10_risk_adjusted_raw_*.csv。两者均非可执行投资推荐，更不是已验证未来预测。全量研究结果存在 research_*.csv。

## KimiCode唯一需要执行的命令

首先更新 GitHub 分支 codex/fund-analysis-all-fund-ranking-20261114，然后在已有数据缓存环境里运行：

~~~
git pull --ff-only
python -m unittest discover -s tests -p "test_*.py" -v
python scripts/run_fund_discovery.py --asof 2026-11-20 --snapshot reports/all_funds/industry_rank_20261120 --data-dir data/all_funds --risk-research-scenarios 256 --risk-research-top 10 --output reports/all_funds/fund_discovery_risk_v4_20261120
~~~

不需要重新抓取已经完整缓存的净值，不需要编造预测收益、费用或合同。没有 --data-dir 的GitHub默认CI只有历史汇总数据，不能精确重建买入持有组合的日度路径风险，只能标注 FULL_NAV_CACHE_REQUIRED。**不要把旧的纯收益诊断榜交付为综合榜。**

## 固定指标与数学口径

1. **收益**：各窗口内真实的历史年化对数净值收益。将每只基金与同一分类中的真实历史候选进行正态—正态经验贝叶斯收缩，以后验下四分位构造保守收益参考；系数0.67448975是标准正态25%分位，不是主观分值权重。它只是历史研究统计量，未经样本外验证，不能称作未来预期收益。
2. **回撤**：逐日观察历史最大回撤；对初始基金仓位w、其余为零回报记账现金的组合，精确计算组合路径回撤。给定B=4%（同时输出1/2/8%敏感性），设 v_t 为相对初始基金净值，p_t 为截至t的基金净值最大值；为保证历史组合回撤不超过B，需要 w*[p_t-v_t-B*(p_t-1)] <= B，对所有t成立。故最大仓位 w_hist = min(1, B / max_t [p_t-v_t-B*(p_t-1)]_+)；分母为0时取1。
3. **下行风险与抗跌**：由对应历史窗口的完整月度收益做stationary block bootstrap，使用256条、持有期6个月、平均区块2个月情景，计算各情景在4%预算下的最大安全仓位；取其5%分位得到w_boot。实际评分仓位 w=min(w_hist,w_boot)。这能约束真实历史最大回撤，并对重复历史月度跌幅导致的尾部回撤保持敏感。年度风险与半年风险不混用。已发生且落在窗口内的2026年债市下跌直接进入日度MDD及月度亏损样本。**这不是对未来4%回撤的硬保证。** 无法通过已知NAV发现被摊余成本法隐藏的风险，只能标明审计隔离。
4. **历史风险预算分数**：将保守年化对数收益mu乘以观察年数h，再换算成初始w、零收益记账现金的假设性组合历史CAGR：
   Score = exp(log(1+w*(exp(mu*h)-1))/h)-1。
   这不同于简单加权收益、回撤两个百分位。高历史收益但40%回撤的基金会自动因w被限制而受到明显降权。对所有同历史窗口基金统一使用B，不再需要人为调整收益分/回撤分权重。
5. **真实估值与合同风险**：如果NAV历史MDD几乎为0但正收益，标记NAV_SMOOTHING_REVIEW，研究数据保留，**不让未核验的经济风险等于0**。合同名称/周期提示也只触发研究与流动性复核，仍计算同一研究评分，记录CONTRACT_REVIEW_REQUIRED；由于退出资格未核实，不进入默认TOP10候选。不能用名称断言基金真的不能交易。
6. **产品/底层行业集中度**：按产品键去重，多只同一已识别指数行业ETF或联接基金只保留最高分的一只作为展示代表；全部原分数、全市场研究排名、合同待核验标志都保留在 research_*.csv。无法可靠识别共同底层行业的产品不能凭空假设一样。

## 验收要求：不能再拿测试通过冒充选基成功

- 四期限风险调整榜均生成非空结果；如完整缓存存在却无任何可比较基金，命令必须失败并说明原因。
- 每条结果至少显示 code、name、historical_return_cagr、risk_standalone_mdd、risk_bootstrap_mdd95、risk_weight_4pct、risk_adjusted_score、risk_adjusted_rank、risk_adjusted_status 和 contract_review_pending。
- 核查高收益高回撤标的：说明其原基金回撤、按4%预算所允许的仓位及风险调整分数；同样收益更大回撤不得因为“收益优先”直接排在更安全产品前面。
- 核查曾异常占榜的007589、008693、007680、008338和025368：逐个披露特征、状态、研究分数及被隔离/不满足窗口的真实原因，不能静默消失。
- 半年TOP10展示中，银行主题ETF只能有一个；其余ETF完整留在raw榜或全研究表。
- 真实数据执行完，KimiCode只需要推送上述四期限TOP10、全目录审计、异常样本复核和可复现日志。**不要自行重新设计权重/阈值/评分方法。**

## 必须正确理解的边界

这个版本解决的是**利用已有NAV直接获得兼顾历史收益与回撤的全市场研究排序**。它不是已经确认未来收益、交易可行或可控制真实组合回撤的结果。更严格的投资执行筛选、历史可交易状态与无幸存者偏差的前推实验，属于后续独立验证，不得把其缺口作为阻止本轮研究榜产生的理由。
