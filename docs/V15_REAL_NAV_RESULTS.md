# v1.5 真实净值回看诊断

> 本页保留旧费用敏感性实验。账户确认无申购费后，请以[零申购费重跑结果](V15_ZERO_SUBSCRIPTION_RESULTS.md)为准。

本报告为研究，非真实账户、非独立样本外、非投资建议。候选名单日期晚于回测窗口。全年窗与半年窗重叠。各窗独立空仓启动，等额日入金。费用为单边申赎压力代理。短窗年化不是实际区间回报。

基金原始净值、累计净值来自天天基金历史净值数据，分红来自基金 F10 分红明细。逐只对照默认九只基金在 2024-12-18 至 2026-11-12 的累计净值减单位净值变化，四只各一条事件与明细一致，其他无差异。使用当前申赎快照，未取得逐日历史规则。估值来自乐咕乐股历史 PE/PB，使用假定披露时间。趋势实测使用基金复权净值，未输入独立长指数序列。

所有窗口均无有效交易案例同时达到费后年化 ≥5% 与组合 MDD ≤4%。SOCP 在半年窗跑通，全年窗因起点前有效共同训练样本不足而明确阻断。旧 A5 空仓启动无实际交易，不视为有效基准。
